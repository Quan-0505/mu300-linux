# F50 内置 OpenWrt 更新包

目标：ZTE F50 / MU300，OpenWrt 25.12.5，Linux 6.18.56 + BTF，Go KDAE 2.2.5 + F50 RAWIP/veth 适配，官方节点小宝 4.3.5-734。

基础源码为 dikeckaan/mu300-linux 的 clean-tf-7.2 分支 53ef7b1；分支名称不代表本包使用 7.2，本包只编译 6.18.56。实际构建提交、内核配置、模块及软件哈希随包提供。借鉴主分支 #230，更新时保留计划任务。

## 设备状态与用户意图

用户希望 Android 完整备份到电脑后，仅使用内置 OpenWrt。历史安装记录实际保留了 Android 启动槽/系统，并缩小 userdata，为 Linux 留出约 4GB 的区域；不能将该历史结果描述成已经彻底删除 Android。当前设备不在电脑旁，此包尚未实机升级，也未实现或验证 Android 分区回收。

本包用于已有内置安装的系统/内核更新，不修改 GPT，不重新缩容，不格式化 userdata，不删除 Android。后续如需回收 Android 空间，必须在连接目标设备、核对完整可恢复备份和实际启动依赖之后另做迁移。基带运行文件、校准/NV、启动链必须保留，不属于可随意删除的数据。

## 使用边界

这不是 armsr 整盘镜像，也不是 Android boot.img，不要用 LuCI 通用整盘 sysupgrade 或 SPD 刷机程序直接写入这些 tar.gz。

实机接回后先检查型号、当前内核、Linux 区域、启动槽、可用空间与备份；停止代理/节点小宝后取得一致性配置快照，将当前 boot、GPT、系统及配置备份到电脑并校验。

更新工具保留原账号、网络/热点/防火墙、代理数据库及 CA、自定义 KixDNS、节点小宝身份、Samba 设置与数据。该逻辑仍需实机验收。旧系统目录和启动镜像作为回退，验证成功前不可运行 clean。不能在没有连上实机时宣称刷入完成。

由于设备离线，此 Release 保持 prerelease，不作为自动更新的 latest。刷入后需要检查蜂窝、Wi-Fi/USB、每次重启自启、代理真实 HTTPS、DNS，以及节点小宝双向 TCP/UDP。广播/mDNS 自动发现没有包含在原来已验证的网关能力中。

## 隐私

仅公开软件、通用服务和构建资产，不包含用户订阅、节点账号、密码、wing.db、SSH 主机密钥、节点小宝绑定身份、基带私有运行文件或设备备份。此包没有默认登录密码；升级时由设备保留自己的账号。新设备需要自己的硬件运行文件和独立登录绑定。
